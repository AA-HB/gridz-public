Support

Besoin d'aide avec Gridz ? Vous trouverez ici comment nous contacter, les réponses aux questions les plus fréquentes, ainsi que les ressources utiles. Nous répondons généralement sous 48 heures.

Nous contacter

Pour toute question, signalement de bug ou suggestion, écrivez-nous par e-mail. Pensez à préciser le modèle de votre appareil et, si possible, une description des étapes permettant de reproduire le problème.

Contacter le support

Questions fréquentes

Comment signaler un bug ?
Envoyez-nous un e-mail via le bouton ci-dessus en décrivant le problème et les étapes pour le reproduire.
Comment suggérer une fonctionnalité ?
Vos idées sont les bienvenues ! Partagez-les par e-mail, nous lisons chaque message.
Je n'arrive pas à me connecter, que faire ?
Vérifiez votre connexion internet puis relancez l'application. Si le problème persiste, contactez-nous en précisant l'adresse e-mail associée à votre compte.
Comment supprimer mon compte ?
Rendez-vous sur la page Suppression de compte et suivez la procédure indiquée.
